Why this works
WCAG governs text and control contrast, not how two panels read apart. So we let text always sit on a dark fill (white ≥ 8.9:1, AAA) and separate the planes with a bright rim + inner highlight + glow. A = rim + soft glow; B = crisp bright rim, raised even darker; C = the raised zone pivots hue (teal→blue) so it differs by colour AND light while staying dark. None rely on a mid-tone fill, so none fall in the trap — and all three look “lit from within,” like sea glass after dark.
