Adored — phone wireframes
The complete phone UI, in order: get in → build → sort → decide → share, plus the add-details & story flow. Brief copy throughout; back-arrow + 3-tab nav; one short H1 per screen.
Long → short
“How do you feel about this one?” → “How do you feel?”
“Which do you love more?” → “Love which more?”
“Continue · Session 2” → “Resume”
“Take a break” → “Pause” · “Bring back” → “Restore”
Phone-specific moves
  • Breadcrumb → back arrow + 3-tab bar.
  • Tier buttons stack 2×2 at 44px+.
  • Story & details collapse behind taps.
  • One H1 per screen, ≤ 3 words.
