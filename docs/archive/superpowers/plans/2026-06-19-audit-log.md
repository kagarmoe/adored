# Audit Log for Permanent Purges — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use `- [ ]`.

**Goal:** Record every permanent item purge in an append-only `audit_log` (who/what/when + counts), written atomically inside the purge transaction, and expose an owner-only read endpoint.

**Architecture:** A new FK-less `audit_log` table; an `AuditLogRepository` constructed on whatever `Database` it's given (injected `db` for reads, `tx` for the atomic write — no optional-`tx` param); `ItemPurgeService.purge` gains the actor and writes one tx-bound audit row after its deletes; `GET /api/collections/[id]/audit` reads owner-scoped, newest-first. Un-mocked DB integration tests are the authoritative proof.

**Tech Stack:** Next.js App Router, Drizzle + postgres-js (real interactive transactions), Vitest (`RUN_DB_TESTS` DB tier), drizzle-kit migrations.

**Spec:** `docs/superpowers/specs/2026-06-19-audit-log-design.md` (rev-2, adversarial-reviewed — all CONCERNS folded).

## Global Constraints
- Commit on `feat/audit-log`; never touch main. graphify-first for any exploration. Don't commit `.claude/settings.json` / `graphify-out/` in task commits.
- TDD: failing test first, run + confirm RED, then minimal code. **Avoid mocking** — the authoritative proofs are un-mocked DB integration tests (mock ONLY `@/lib/auth`, `@/lib/db`, and `@vercel/blob`'s `del`). The atomicity test is the one sanctioned exception (it spies the audit `record` to force a failure the FK-less table can't otherwise produce).
- **Tx-binding is structural, not optional:** the purge audit write is `await new AuditLogRepository(tx).record(...)` — built on `tx`, like every other write inside `withTransaction`. There is no `record(entry, tx?)` overload. A non-tx audit write must be impossible to express at the purge call site.
- **Append-only:** no UPDATE/DELETE repo method or route on `audit_log`. Immutability is application-level (documented limitation).
- **`metadata` carries counts + ids only** — never blob URLs, emails, or item names.
- `?limit=` is always clamped server-side: `Number.isFinite(n) ? Math.min(200, Math.max(1, Math.trunc(n))) : 100`.
- Out of scope: `purgeCollection`'s own `"collection.purge"` audit write (next PR — this PR builds the table/repo it will use).

```ts
    action: text("action").notNull(),
    targetType: text("target_type").notNull(),
    targetId: text("target_id").notNull(),
    collectionId: text("collection_id").notNull(),
    metadata: jsonb("metadata"),
    createdAt: timestamp("created_at").defaultNow().notNull(),

  (table) => ({

      table.createdAt,
```

- [ ] **Step 3: Implement the repo**

```ts
import type { Database } from "@/lib/db";
import { eq, desc } from "drizzle-orm";
import { auditLogTable } from "@/lib/db/schema";
import { generateId } from "@/lib/id";
import type { AuditLog, AuditAction, AuditTargetType, NewAuditLog } from "@/types/domain";

const DEFAULT_LIMIT = 100;
const MAX_LIMIT = 200;

// Always clamp: a hostile/absent ?limit= must never produce an unbounded scan.
function clampLimit(raw: number | undefined): number {
  const n = Number(raw);
  return Number.isFinite(n) ? Math.min(MAX_LIMIT, Math.max(1, Math.trunc(n))) : DEFAULT_LIMIT;
}

// Constructed on whatever Database it's given: the injected db for reads, a tx
// for the atomic purge write. No optional-tx overload — a non-tx write must be
// impossible to express (see ItemPurgeService).
export class AuditLogRepository {
  constructor(private db: Database) {}

  async record(entry: NewAuditLog): Promise<void> {
    await this.db.insert(auditLogTable).values({
      id: generateId("audit"),
      actorId: entry.actorId,
      action: entry.action,
      targetType: entry.targetType,
      targetId: entry.targetId,
      collectionId: entry.collectionId,
      metadata: entry.metadata ?? null,
    });
  }

  // Newest-first, total order (createdAt then id) so same-ms ties are stable.
  async findByCollection(collectionId: string, opts?: { limit?: number }): Promise<AuditLog[]> {
    const rows = await this.db
      .select()
      .from(auditLogTable)
      .where(eq(auditLogTable.collectionId, collectionId))
      .orderBy(desc(auditLogTable.createdAt), desc(auditLogTable.id))
      .limit(clampLimit(opts?.limit));
    return rows.map((row) => ({
      id: row.id,
      actorId: row.actorId,
      action: row.action as AuditAction,
      targetType: row.targetType as AuditTargetType,
      targetId: row.targetId,
      collectionId: row.collectionId,
      metadata: (row.metadata as Record<string, number> | null) ?? null,
      createdAt: row.createdAt,
    }));
  }
}
```

```ts
import type { Item } from "@/types/domain";
import { AuditLogRepository } from "@/server/repositories/implementations/AuditLogRepository";
// ...existing imports

async purge(item: Item, actorId: string): Promise<void> {
  if (await this.sortResultItemRepo.existsByItem(item.id)) {
    throw new ItemInResultError();
  }

  const blobKeys = await withTransaction(this.db, async (tx) => {
    const preferencesDeleted = await new CollectionPreferenceItemRepository(tx).deleteByItem(item.id);
    const keys = await new PhotoRepository(tx).hardDeleteByItem(item.id);
    await new ItemRepository(tx).hardDelete(item.id);
    // Tx-bound by construction — a committed purge always has exactly one audit
    // row; if this insert throws, the whole purge rolls back.
    await new AuditLogRepository(tx).record({
      actorId,
      action: "item.purge",
      targetType: "item",
      targetId: item.id,
      collectionId: item.collectionId,
      metadata: { photosDeleted: keys.length, preferencesDeleted },
    });
    return keys;
  });

  // Best-effort, post-commit (unchanged).
  const results = await Promise.allSettled(
    blobKeys.filter((k) => k.startsWith("http")).map((k) => del(k)),
  );
  for (const r of results) {
    if (r.status === "rejected") {
      console.error("ItemPurgeService: blob del failed (orphaned, sweepable)", r.reason);
    }
  }
}
```

```ts
import { NextRequest, NextResponse } from "next/server";
import { requireAuth } from "@/lib/auth";
import { getDb } from "@/lib/db";
import { requireApiCollectionOwner } from "@/server/dal/collection-access";
import { AuditLogRepository } from "@/server/repositories/implementations/AuditLogRepository";

// Owner-only read of a collection's permanent-purge trail. 404 (absent) is
// returned BEFORE 403 (not owner) by the gate — the existence-oracle convention
// (API.md §46). The purge trail is the owner's concern; a member must not read it.
export async function GET(
  request: NextRequest,
  { params }: { params: { id: string } },
) {
  try {
    const user = await requireAuth();
    const db = getDb();

    const owned = await requireApiCollectionOwner(db, params.id, user.id);
    if (owned instanceof NextResponse) return owned; // 404 absent / 403 not owner

    const limitParam = request.nextUrl.searchParams.get("limit");
    const entries = await new AuditLogRepository(db).findByCollection(params.id, {
      limit: limitParam == null ? undefined : Number(limitParam), // repo clamps
    });
    return NextResponse.json(entries);
  } catch (error) {
    const status = error instanceof Error && error.message === "Unauthorized" ? 401 : 500;
    return NextResponse.json(
      { error: error instanceof Error ? error.message : "Unknown error" },
      { status },
    );
  }
}
```
